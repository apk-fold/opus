# Opus

برنامهٔ اندرویدی سفارشی برای گوش دادن به موسیقی‌تان از یک سرور [Navidrome](https://www.navidrome.org/) (Subsonic API).
تم تیره با رنگ قابل تنظیم، انیمیشن‌های GSAP، متن ترانهٔ همگام، حالت آفلاین و کنترل deemix از داخل برنامه.
با [Capacitor](https://capacitorjs.com/) به APK تبدیل شده و چیدمانی سازگار با Galaxy Z Fold (بسته / باز) دارد.

## تازه‌های v6
- **پخش‌کنندهٔ بومی Android (ExoPlayer/Media3)، مانند Subtracks**: صف پخش را یک سرویس Android پخش می‌کند، نه صفحهٔ وب. موسیقی با صفحهٔ خاموش یا برنامه در پس‌زمینه از آهنگی به آهنگ دیگر می‌رود و اعلان (پخش/مکث/قبلی/بعدی) پخش‌کنندهٔ واقعی را کنترل می‌کند.
- محدودیت‌های حالت بومی: بدون اکولایزر و محوشدگی متقاطع (به‌جایش پخش پیوستهٔ پخش‌کنندهٔ بومی).

## تازه‌های v4
- آهنگ دیگر از وسط شروع نمی‌شود: موقعیت ادامهٔ پخش قدیمی فقط روی آهنگی اعمال می‌شود که به آن تعلق دارد.
- پخش پس‌زمینهٔ مطمئن‌تر (قفل CPU/Wi-Fi هنگام پخش، نظارت بر رفتن به آهنگ بعدی). تنظیمات › پخش در پس‌زمینه: دکمه‌ای برای برداشتن محدودیت باتری.
- آفلاین: مرتب‌سازی هنرمندان، آلبوم‌ها و فهرست‌های پخش (A→Z، جدیدترین، بیشترین آهنگ، حجیم‌ترین) و منوی ⋯ › «دانلود همهٔ فهرست‌های پخش من».
- APK با هر به‌روزرسانی به‌طور خودکار توسط GitHub Actions ساخته می‌شود (زبانهٔ Releases).

## دانلود APK

➡️ **[دانلود Opus v6 (`opus.apk`)](https://github.com/apk-fold/opus/raw/main/opus.apk)**، حجم ۴٫۶ مگابایت. فایل در
فهرست فایل‌های مخزن هم دیده می‌شود.

چکیدهٔ SHA-256 برای بررسی فایل: `63dc6c04ec14fc8d3ec5ed4c77b54b1d70bf6199b5b57f6256a27404fc1c16af`

نصب روی Android:
1. فایل `opus.apk` را مستقیماً روی گوشی دانلود کنید.
2. فایل را باز کنید. Android اجازهٔ نصب از این منبع (مرورگر یا مدیر فایل) را می‌خواهد: بپذیرید.
3. **نصب** را بزنید.

نکته‌ها:
- این یک APK نسخهٔ **debug** است (امضاشده با کلید اشکال‌زدایی Android Studio). اگر نسخه‌ای از Opus با امضای دیگری دارید،
  اول آن را حذف کنید.
- در Android 13 به بالا، اعلان‌های Opus را مجاز کنید (کنترل‌های رسانه روی صفحهٔ قفل) و باتری برنامه را روی
  «بدون محدودیت» بگذارید تا پخش با صفحهٔ خاموش ادامه یابد.
- گوشی باید بتواند به سرور Navidrome شما دسترسی داشته باشد (برای مثال از طریق Tailscale).

## قابلیت‌های اصلی

### تازه‌های v3
- **اشاره‌های شبیه iPhone** (تنظیمات › اشاره‌ها و میان‌برها): کشیدن به پایین در بالای صفحه منوی ⋯ آن را باز می‌کند، کشیدن
  به پایین روی پخش‌کننده منوی آهنگ را، به بالا صف پخش را، دو ضربه روی کاور = پسندیدن،
  نگه داشتن طولانی روی آهنگ، آلبوم، فهرست پخش یا هنرمند = منوی آن، کشیدن آهنگ به راست = پخش بعدی، به چپ =
  افزودن به صف. همه‌چیز قابل تنظیم است.
- **تم‌ها**: تیره، AMOLED (سیاه خالص) و روشن.
- **Fold باز**: کتابخانه در سمت چپ، پخش‌کنندهٔ ثابت در سمت راست و متن ترانه (یا صف) زیر آن. در حالت بسته برنامه
  به حالت عادی برمی‌گردد.
- **پوشه‌های فهرست پخش**: مرتب‌سازی محلی روی گوشی (Navidrome از پوشه پشتیبانی نمی‌کند).
- **وارد کردن فهرست‌های پخش Spotify، YouTube و YouTube Music** با پیوند، بدون کلید API: آهنگ‌ها در
  کتابخانه یافته می‌شوند، آهنگ‌های ناموجود را می‌توان به deemix فرستاد و فهرست پخش را می‌توان در Navidrome دوباره ساخت.
- **تشخیص تکراری‌ها**: یک آهنگ در چند نسخه یا کیفیت، بهترین کیفیت در بالا.
- **deemix مورد به مورد**: کیفیت (FLAC، 320، 128) و فهرست پخش مقصد در هر بار دانلود انتخاب می‌شود.
- **Android**: میان‌برهای آیکون برنامه (Flow، آفلاین، جست‌وجو) و ویجت صفحهٔ اصلی.

### گوش دادن و کشف
- **Flow** (میکس بی‌پایان بر اساس سلیقهٔ شما، با حال‌وهوا)، **میکس روز**، **رادیو** بر اساس یک آهنگ یا هنرمند.
- **گوهرهای فراموش‌شده**، **در چنین روزی**، **تازه‌های هنرمندان شما**، **آزمون کور**، **تاریخچه**، **Replay**.
- متن ترانهٔ همگام و لمسی، صف پخش، تایمر خواب، اکولایزر، ReplayGain، محوشدگی متقاطع، حالت خودرو.
- حالت آفلاین در زبانه‌ها (آهنگ‌ها، هنرمندان، آلبوم‌ها، فهرست‌های پخش).
- بیش از ۴۰ قابلیت که در تنظیمات › قابلیت‌ها روشن یا خاموش می‌شوند.

## پیکربندی

در نخستین اجرا، نشانی سرور Navidrome خود (برای مثال `http://mon-serveur:4533`)، نام کاربری و
گذرواژه را وارد کنید. رنگ تم در تنظیمات › ظاهر تغییر می‌کند.

### deemix (اختیاری)
Opus می‌تواند سرویس کوچکی را که روی سرور شما نصب شده کنترل کند (پوشهٔ `server/`، ببینید `server/README-serveur.md`) تا
آهنگ‌ها را از Deezer در پوشهٔ موسیقی Navidrome دانلود کند. ARL مربوط به Deezer در برنامه وارد می‌شود.
هشدار: این نوع استفاده خلاف شرایط استفادهٔ Deezer است.

## ساختن توسط خودتان (Windows)

پیش‌نیازها: Node.js 20+، Android Studio همراه Android SDK، و **JDK 21** (Gradle 8.14 هنوز نمی‌تواند کلاس‌های
کامپایل‌شده با Java 27 یا جدیدتر را بخواند).

```
npm install
npm run android:add     # پوشهٔ android/ را می‌سازد و اصلاحات را اعمال می‌کند
npm run sync            # ساخت وب + همگام‌سازی Capacitor
cd android
gradlew.bat assembleDebug
```

APK در `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

اگر Gradle از Java اشتباه استفاده می‌کند، پیش از ساخت `JAVA_HOME` را روی JDK 21 بگذارید:

```
set JAVA_HOME=C:\Program Files\Java\jdk-21.0.12.1
set PATH=%JAVA_HOME%\bin;%PATH%
```

برای آزمودن بدون سرور: `npm run mock` (Navidrome ساختگی، اطلاعات ورود `test` / `test`) و سپس `npm run dev`.

## محدودیت‌های شناخته‌شده
- وارد کردن از Spotify / YouTube صفحه‌های عمومی این سایت‌ها را می‌خواند که قالبشان اغلب تغییر می‌کند. اگر ناموفق بود، چسباندن
  فهرستی به شکل «هنرمند - عنوان» همیشه کار می‌کند. بدون حساب کاربری فقط ۱۰۰ آهنگ اول خوانده می‌شود.
- حالت Fold، ویجت و اشاره‌ها با شبیه‌سازی بررسی شده‌اند، هنوز روی همهٔ دستگاه‌ها نه.
- نمایشگر بصری صدا فقط تزئینی است.
- اکولایزر نیاز دارد که سرور شما CORS را روی جریان‌های صوتی مجاز کند (`Access-Control-Allow-Origin`).
