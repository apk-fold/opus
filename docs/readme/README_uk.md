# Opus

Власний Android-застосунок для прослуховування музики із сервера [Navidrome](https://www.navidrome.org/) (Subsonic API).
Темна тема з налаштовуваним кольором, анімації GSAP, синхронізовані тексти пісень, офлайн-режим і керування deemix просто із застосунку.
Запаковано в APK за допомогою [Capacitor](https://capacitorjs.com/), з розміткою, адаптованою під Galaxy Z Fold (у складеному й розкладеному вигляді).

## Що нового у v6
- **Нативний Android-плеєр (ExoPlayer/Media3), як у Subtracks**: чергу відтворює служба Android, а не вебсторінка. Треки змінюють один одного за вимкненого екрана чи коли застосунок у фоні, а сповіщення (відтворення/пауза/назад/далі) керує справжнім плеєром.
- Обмеження нативного режиму: немає еквалайзера й плавного переходу (замість нього — відтворення без пауз нативного плеєра).

## Що нового у v4
- Трек більше не починається з середини: стара позиція продовження застосовується лише до того треку, якому вона належить.
- Надійніше фонове відтворення (блокування CPU/Wi-Fi під час відтворення, контроль переходу до наступного треку). Налаштування › Фонове відтворення: кнопка для зняття обмеження батареї.
- Офлайн: сортування виконавців, альбомів і плейлистів (A→Z, нещодавні, найбільше треків, найбільші) і меню ⋯ › «Завантажити всі мої плейлисти».
- APK автоматично збирається через GitHub Actions після кожного оновлення (вкладка Releases).

## Завантажити APK

➡️ **[Завантажити Opus v6 (`opus.apk`)](https://github.com/apk-fold/opus/raw/main/opus.apk)**, 4,6 МБ. Файл також видно
в списку файлів репозиторію.

Контрольна сума SHA-256 для перевірки файлу: `63dc6c04ec14fc8d3ec5ed4c77b54b1d70bf6199b5b57f6256a27404fc1c16af`

Установлення на Android:
1. Завантаж `opus.apk` просто на телефон.
2. Відкрий файл. Android попросить дозволити встановлення з цього джерела (браузер або файловий менеджер): погодься.
3. Натисни **Установити**.

Примітки:
- Це **debug**-версія APK (підписана налагоджувальним ключем Android Studio). Якщо в тебе вже є Opus з іншим підписом,
  спершу видали його.
- На Android 13+ дозволь Opus сповіщення (керування відтворенням на екрані блокування) і встанови для застосунку режим батареї
  «Без обмежень», щоб музика грала за вимкненого екрана.
- Телефон має мати доступ до твого сервера Navidrome (наприклад, через Tailscale).

## Основні можливості

### Що нового у v3
- **Жести як на iPhone** (Налаштування › Жести та ярлики): потягнути вниз угорі сторінки — відкрити її меню ⋯, свайп
  вниз на плеєрі — меню треку, вгору — черга, подвійний дотик до обкладинки — «подобається»,
  довге натискання на трек, альбом, плейлист чи виконавця — його меню, свайп треку праворуч — грати наступним, ліворуч —
  додати в чергу. Усе налаштовується.
- **Теми**: темна, AMOLED (чисто чорна) і світла.
- **Розкладений Fold**: медіатека ліворуч, закріплений плеєр праворуч, під ним тексти (або черга). У складеному вигляді застосунок
  знову виглядає як звичайно.
- **Теки плейлистів**: локальна організація на телефоні (Navidrome не підтримує теки).
- **Імпорт плейлистів зі Spotify, YouTube і YouTube Music** за посиланням, без API-ключа: треки шукаються в
  медіатеці, відсутні можна надіслати в deemix, а плейлист — відтворити в Navidrome.
- **Пошук дублікатів**: той самий трек у кількох копіях чи якостях, найкраща якість першою.
- **deemix щоразу окремо**: якість (FLAC, 320, 128) і цільовий плейлист вибираються під час кожного запуску завантаження.
- **Android**: ярлики на значку застосунку (Flow, Офлайн, Пошук) і віджет для головного екрана.

### Прослуховування й відкриття
- **Flow** (нескінченний мікс за твоїм смаком, із настроями), **Мікс дня**, **радіо** за треком або виконавцем.
- **Забуті перлини**, **Цього дня**, **Новинки твоїх виконавців**, **Вгадай мелодію**, **Історія**, **Replay**.
- Синхронізовані тексти з переходом за дотиком, черга, таймер сну, еквалайзер, ReplayGain, плавний перехід, автомобільний режим.
- Офлайн-режим за вкладками (Треки, Виконавці, Альбоми, Плейлисти).
- Понад 40 функцій, які можна вмикати й вимикати в Налаштування › Функції.

## Налаштування

Під час першого запуску введи адресу свого сервера Navidrome (наприклад, `http://mon-serveur:4533`), ім'я користувача і
пароль. Колір теми змінюється в Налаштування › Вигляд.

### deemix (необов'язково)
Opus може керувати невеликою службою, встановленою на твоєму сервері (тека `server/`, див. `server/README-serveur.md`), щоб
завантажувати треки з Deezer у музичну теку Navidrome. ARL від Deezer вводиться в застосунку.
Увага: таке використання порушує умови використання Deezer.

## Зібрати самостійно (Windows)

Вимоги: Node.js 20+, Android Studio з Android SDK і **JDK 21** (Gradle 8.14 поки не читає класи,
скомпільовані Java 27 і новіших версій).

```
npm install
npm run android:add     # створює теку android/ і застосовує виправлення
npm run sync            # веб-збірка + синхронізація Capacitor
cd android
gradlew.bat assembleDebug
```

APK з'явиться в `android/app/build/outputs/apk/debug/app-debug.apk`.

Якщо Gradle використовує не ту Java, перед збиранням вкажи в `JAVA_HOME` шлях до JDK 21:

```
set JAVA_HOME=C:\Program Files\Java\jdk-21.0.12.1
set PATH=%JAVA_HOME%\bin;%PATH%
```

Спробувати без сервера: `npm run mock` (фальшивий Navidrome, логін і пароль `test` / `test`), потім `npm run dev`.

## Відомі обмеження
- Імпорт зі Spotify / YouTube читає публічні сторінки цих сайтів, формат яких часто змінюється. Якщо не вдалося,
  вставлення списку «Виконавець - Назва» працює завжди. Без облікового запису читаються лише перші 100 треків.
- Режим Fold, віджет і жести перевірено в симуляції, але ще не на всіх пристроях.
- Візуалізатор — декоративний.
- Для еквалайзера сервер має дозволяти CORS для аудіопотоків (`Access-Control-Allow-Origin`).
