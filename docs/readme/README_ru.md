# Opus

Собственное Android-приложение для прослушивания музыки с сервера [Navidrome](https://www.navidrome.org/) (Subsonic API).
Тёмная тема с настраиваемым цветом, анимации GSAP, синхронизированные тексты песен, офлайн-режим и управление deemix прямо из приложения.
Упаковано в APK с помощью [Capacitor](https://capacitorjs.com/), с раскладкой, адаптированной под Galaxy Z Fold (в сложенном и разложенном виде).

## Что нового в v6
- **Нативный Android-плеер (ExoPlayer/Media3), как в Subtracks**: очередь воспроизводит служба Android, а не веб-страница. Треки сменяют друг друга при выключенном экране или когда приложение в фоне, а уведомление (воспроизведение/пауза/назад/вперёд) управляет настоящим плеером.
- Ограничения нативного режима: нет эквалайзера и плавного перехода (вместо него — воспроизведение без пауз нативного плеера).

## Что нового в v4
- Трек больше не начинается с середины: старая позиция продолжения применяется только к тому треку, к которому она относится.
- Более надёжное фоновое воспроизведение (блокировка CPU/Wi-Fi во время воспроизведения, контроль перехода к следующему треку). Настройки › Фоновое воспроизведение: кнопка для снятия ограничения батареи.
- Офлайн: сортировка исполнителей, альбомов и плейлистов (A→Z, недавние, больше всего треков, самые большие) и меню ⋯ › «Скачать все мои плейлисты».
- APK автоматически собирается через GitHub Actions при каждом обновлении (вкладка Releases).

в списке файлов репозитория.

Контрольная сумма SHA-256 для проверки файла: `63dc6c04ec14fc8d3ec5ed4c77b54b1d70bf6199b5b57f6256a27404fc1c16af`

Установка на Android:
1. Скачай `opus.apk` прямо на телефон.
2. Открой файл. Android попросит разрешить установку из этого источника (браузер или файловый менеджер): согласись.
3. Нажми **Установить**.

Примечания:
- Это **debug**-версия APK (подписана отладочным ключом Android Studio). Если у тебя уже стоит Opus с другой подписью,
  сначала удали его.
- На Android 13+ разреши Opus уведомления (управление воспроизведением на экране блокировки) и выставь для приложения режим батареи
  «Без ограничений», чтобы музыка играла при выключенном экране.
- Телефон должен иметь доступ к твоему серверу Navidrome (например, через Tailscale).

## Основные возможности

### Что нового в v3
- **Жесты как на iPhone** (Настройки › Жесты и ярлыки): потянуть вниз в верхней части страницы — открыть её меню ⋯, свайп
  вниз на плеере — меню трека, вверх — очередь, двойное касание обложки — «нравится»,
  долгое нажатие на трек, альбом, плейлист или исполнителя — его меню, свайп трека вправо — играть следующим, влево —
  добавить в очередь. Всё настраивается.
- **Темы**: тёмная, AMOLED (чисто чёрная) и светлая.
- **Разложенный Fold**: медиатека слева, закреплённый плеер справа, под ним тексты (или очередь). В сложенном виде приложение
  снова выглядит как обычно.
- **Папки плейлистов**: локальная организация на телефоне (Navidrome не поддерживает папки).
- **Импорт плейлистов из Spotify, YouTube и YouTube Music** по ссылке, без API-ключа: треки находятся в
  медиатеке, недостающие можно отправить в deemix, а плейлист — воссоздать в Navidrome.
- **Поиск дубликатов**: один и тот же трек в нескольких копиях или качествах, лучшее качество первым.
- **deemix в каждом конкретном случае**: качество (FLAC, 320, 128) и целевой плейлист выбираются при каждом запуске загрузки.
- **Android**: ярлыки на значке приложения (Flow, Офлайн, Поиск) и виджет для главного экрана.

### Прослушивание и открытия
- **Flow** (бесконечный микс по твоему вкусу, с настроениями), **Микс дня**, **радио** по треку или исполнителю.
- **Забытые жемчужины**, **В этот день**, **Новинки твоих исполнителей**, **Угадай мелодию**, **История**, **Replay**.
- Синхронизированные тексты с переходом по касанию, очередь, таймер сна, эквалайзер, ReplayGain, плавный переход, автомобильный режим.
- Офлайн-режим по вкладкам (Треки, Исполнители, Альбомы, Плейлисты).
- Более 40 функций, которые можно включать и выключать в Настройки › Функции.

## Настройка

При первом запуске введи адрес своего сервера Navidrome (например, `http://mon-serveur:4533`), логин и
пароль. Цвет темы меняется в Настройки › Внешний вид.

### deemix (необязательно)
Opus может управлять небольшой службой, установленной на твоём сервере (папка `server/`, см. `server/README-serveur.md`), чтобы
скачивать треки из Deezer в музыкальную папку Navidrome. ARL от Deezer вводится в приложении.
Внимание: такое использование нарушает условия использования Deezer.

## Собрать самому (Windows)

Требования: Node.js 20+, Android Studio с Android SDK и **JDK 21** (Gradle 8.14 пока не читает классы,
скомпилированные Java 27 и новее).

```
npm install
npm run android:add     # создаёт папку android/ и применяет исправления
npm run sync            # веб-сборка + синхронизация Capacitor
cd android
gradlew.bat assembleDebug
```

APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.

Если Gradle использует не ту Java, перед сборкой укажи в `JAVA_HOME` путь к JDK 21:

```
set JAVA_HOME=C:\Program Files\Java\jdk-21.0.12.1
set PATH=%JAVA_HOME%\bin;%PATH%
```

Попробовать без сервера: `npm run mock` (фальшивый Navidrome, логин и пароль `test` / `test`), затем `npm run dev`.

## Известные ограничения
- Импорт из Spotify / YouTube читает публичные страницы этих сайтов, формат которых часто меняется. Если не получилось,
  вставка списка «Исполнитель - Название» работает всегда. Без аккаунта читаются только первые 100 треков.
- Режим Fold, виджет и жесты проверены в симуляции, но ещё не на всех устройствах.
- Визуализатор — декоративный.
- Для эквалайзера сервер должен разрешать CORS для аудиопотоков (`Access-Control-Allow-Origin`).
