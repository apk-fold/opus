# Opus

ഒരു [Navidrome](https://www.navidrome.org/) സെർവറിൽ (Subsonic API) നിന്ന് നിങ്ങളുടെ സംഗീതം കേൾക്കാൻ പ്രത്യേകം നിർമ്മിച്ച Android ആപ്പ്.
നിറം മാറ്റാവുന്ന ഡാർക്ക് തീം, GSAP ആനിമേഷനുകൾ, സിങ്ക് ചെയ്ത വരികൾ, ഓഫ്‌ലൈൻ മോഡ്, ആപ്പിൽ നിന്ന് deemix നിയന്ത്രണം.
[Capacitor](https://capacitorjs.com/) ഉപയോഗിച്ച് APK ആയി പാക്ക് ചെയ്തത്, Galaxy Z Fold-ന് (മടക്കിയത് / തുറന്നത്) അനുയോജ്യമായ ലേഔട്ടോടെ.

## v6-ലെ പുതുമകൾ
- **Subtracks പോലെ, Android നേറ്റീവ് പ്ലേയർ (ExoPlayer/Media3)**: ക്യൂ ഇപ്പോൾ വെബ് പേജല്ല, ഒരു Android സേവനമാണ് പ്ലേ ചെയ്യുന്നത്. സ്ക്രീൻ ഓഫായിരിക്കുമ്പോഴും ആപ്പ് പശ്ചാത്തലത്തിലായിരിക്കുമ്പോഴും പാട്ടുകൾ തുടർന്നുപോകും, അറിയിപ്പ് (പ്ലേ/പോസ്/മുമ്പത്തേത്/അടുത്തത്) യഥാർത്ഥ പ്ലേയറിനെ നിയന്ത്രിക്കുന്നു.
- നേറ്റീവ് മോഡിന്റെ പരിമിതികൾ: ഇക്വലൈസറും ക്രോസ്‌ഫേഡും ഇല്ല (നേറ്റീവ് പ്ലേയറിന്റെ ഇടവേളയില്ലാത്ത പ്ലേബാക്ക് പകരം).

## v4-ലെ പുതുമകൾ
- ഒരു പാട്ട് ഇനി പാതിയിൽ നിന്ന് തുടങ്ങില്ല: പഴയ തുടർച്ചാ സ്ഥാനം അത് ഉൾപ്പെടുന്ന പാട്ടിന് മാത്രമേ ബാധകമാകൂ.
- കൂടുതൽ ഉറപ്പുള്ള പശ്ചാത്തല പ്ലേബാക്ക് (പ്ലേ ചെയ്യുമ്പോൾ CPU/Wi-Fi ലോക്ക്, അടുത്ത പാട്ടിലേക്കുള്ള മാറ്റം നിരീക്ഷിക്കുന്നു). ക്രമീകരണങ്ങൾ › പശ്ചാത്തല പ്ലേബാക്ക്: ബാറ്ററി നിയന്ത്രണം നീക്കാനുള്ള ബട്ടൺ.
- ഓഫ്‌ലൈൻ: കലാകാരന്മാർ, ആൽബങ്ങൾ, പ്ലേലിസ്റ്റുകൾ എന്നിവയുടെ ക്രമീകരണം (A→Z, പുതിയവ, ഏറ്റവും കൂടുതൽ പാട്ടുകൾ, ഏറ്റവും വലുത്) കൂടാതെ ⋯ മെനു › "എന്റെ എല്ലാ പ്ലേലിസ്റ്റുകളും ഡൗൺലോഡ് ചെയ്യുക".
- ഓരോ അപ്‌ഡേറ്റിലും GitHub Actions APK സ്വയമേവ ബിൽഡ് ചെയ്യുന്നു (Releases ടാബ്).

## APK ഡൗൺലോഡ് ചെയ്യുക

➡️ **[Opus v6 ഡൗൺലോഡ് ചെയ്യുക (`opus.apk`)](https://github.com/apk-fold/opus/raw/main/opus.apk)**, 4.6 MB. ഫയൽ
റിപ്പോസിറ്ററിയുടെ ഫയൽ ലിസ്റ്റിലും കാണാം.

ഫയൽ പരിശോധിക്കാനുള്ള SHA-256 ഹാഷ്: `63dc6c04ec14fc8d3ec5ed4c77b54b1d70bf6199b5b57f6256a27404fc1c16af`

Android-ൽ ഇൻസ്റ്റാൾ ചെയ്യൽ:
1. `opus.apk` നേരിട്ട് ഫോണിലേക്ക് ഡൗൺലോഡ് ചെയ്യുക.
2. ഫയൽ തുറക്കുക. ഈ ഉറവിടത്തിൽ (ബ്രൗസർ അല്ലെങ്കിൽ ഫയൽ മാനേജർ) നിന്ന് ഇൻസ്റ്റാൾ ചെയ്യാൻ Android അനുമതി ചോദിക്കും: അംഗീകരിക്കുക.
3. **ഇൻസ്റ്റാൾ ചെയ്യുക** ടാപ്പ് ചെയ്യുക.

കുറിപ്പുകൾ:
- ഇത് ഒരു **debug** APK ആണ് (Android Studio-യുടെ ഡീബഗ് കീ ഉപയോഗിച്ച് സൈൻ ചെയ്തത്). മറ്റൊരു രീതിയിൽ സൈൻ ചെയ്ത Opus പതിപ്പ് ഇതിനകം ഉണ്ടെങ്കിൽ,
  ആദ്യം അത് അൺഇൻസ്റ്റാൾ ചെയ്യുക.
- Android 13+-ൽ, Opus-ന് അറിയിപ്പുകൾ അനുവദിക്കുക (ലോക്ക് സ്ക്രീനിലെ മീഡിയ നിയന്ത്രണങ്ങൾ), സ്ക്രീൻ ഓഫായിരിക്കുമ്പോഴും പ്ലേബാക്ക് തുടരാൻ ആപ്പിന്റെ ബാറ്ററി
  "നിയന്ത്രണമില്ലാത്തത്" ആയി സജ്ജമാക്കുക.
- ഫോണിന് നിങ്ങളുടെ Navidrome സെർവറിലേക്ക് എത്താൻ കഴിയണം (ഉദാഹരണത്തിന് Tailscale വഴി).

## പ്രധാന ഫീച്ചറുകൾ

### v3-ലെ പുതുമകൾ
- **iPhone ശൈലിയിലുള്ള ജെസ്‌ചറുകൾ** (ക്രമീകരണങ്ങൾ › ജെസ്‌ചറുകളും കുറുക്കുവഴികളും): പേജിന്റെ മുകളിൽ താഴേക്ക് വലിച്ചാൽ അതിന്റെ ⋯ മെനു തുറക്കും, പ്ലേയറിൽ
  താഴേക്ക് സ്വൈപ്പ് ചെയ്താൽ പാട്ടിന്റെ മെനു, മുകളിലേക്ക് ക്യൂ, കവറിൽ ഇരട്ട ടാപ്പ് = ഇഷ്ടപ്പെട്ടു,
  ഒരു പാട്ടിലോ ആൽബത്തിലോ പ്ലേലിസ്റ്റിലോ കലാകാരനിലോ നീണ്ട അമർത്തൽ = അതിന്റെ മെനു, പാട്ട് വലത്തേക്ക് സ്വൈപ്പ് = അടുത്തതായി പ്ലേ ചെയ്യുക, ഇടത്തേക്ക് =
  ക്യൂവിൽ ചേർക്കുക. എല്ലാം ക്രമീകരിക്കാം.
- **തീമുകൾ**: ഡാർക്ക്, AMOLED (ശുദ്ധമായ കറുപ്പ്), ലൈറ്റ്.
- **തുറന്ന Fold**: ഇടതുവശത്ത് ലൈബ്രറി, വലതുവശത്ത് ഉറപ്പിച്ച പ്ലേയർ, താഴെ വരികൾ (അല്ലെങ്കിൽ ക്യൂ). മടക്കുമ്പോൾ ആപ്പ്
  സാധാരണ രൂപത്തിലേക്ക് മടങ്ങും.
- **പ്ലേലിസ്റ്റ് ഫോൾഡറുകൾ**: ഫോണിൽ ലോക്കലായുള്ള ക്രമീകരണം (Navidrome ഫോൾഡറുകൾ പിന്തുണയ്ക്കുന്നില്ല).
- **Spotify, YouTube, YouTube Music പ്ലേലിസ്റ്റുകൾ** ലിങ്ക് വഴി ഇമ്പോർട്ട് ചെയ്യുക, API കീ ഇല്ലാതെ: പാട്ടുകൾ
  ലൈബ്രറിയിൽ കണ്ടെത്തുന്നു, ഇല്ലാത്തവ deemix-ലേക്ക് അയയ്ക്കാം, പ്ലേലിസ്റ്റ് Navidrome-ൽ വീണ്ടും സൃഷ്ടിക്കാം.
- **ഡ്യൂപ്ലിക്കേറ്റ് കണ്ടെത്തൽ**: ഒരേ പാട്ട് പല പകർപ്പുകളിലോ ഗുണനിലവാരങ്ങളിലോ, മികച്ച ഗുണനിലവാരം ആദ്യം.
- **ഓരോ തവണയും deemix ക്രമീകരണം**: ഓരോ ഡൗൺലോഡിലും ഗുണനിലവാരവും (FLAC, 320, 128) ലക്ഷ്യ പ്ലേലിസ്റ്റും തിരഞ്ഞെടുക്കാം.
- **Android**: ആപ്പ് ഐക്കൺ കുറുക്കുവഴികൾ (Flow, ഓഫ്‌ലൈൻ, തിരയൽ), ഹോം സ്ക്രീൻ വിജറ്റ്.

### കേൾക്കലും കണ്ടെത്തലും
- **Flow** (നിങ്ങളുടെ അഭിരുചിക്കനുസരിച്ചുള്ള അവസാനമില്ലാത്ത മിക്സ്, മാനസികാവസ്ഥകളോടെ), **ഇന്നത്തെ മിക്സ്**, ഒരു പാട്ടിൽ നിന്നോ കലാകാരനിൽ നിന്നോ **റേഡിയോ**.
- **മറന്നുപോയ രത്നങ്ങൾ**, **ഈ ദിവസം**, **നിങ്ങളുടെ കലാകാരന്മാരുടെ പുതിയവ**, **ബ്ലൈൻഡ് ടെസ്റ്റ്**, **ചരിത്രം**, **Replay**.
- സ്പർശിക്കാവുന്ന സിങ്ക് ചെയ്ത വരികൾ, ക്യൂ, സ്ലീപ്പ് ടൈമർ, ഇക്വലൈസർ, ReplayGain, ക്രോസ്‌ഫേഡ്, കാർ മോഡ്.
- ടാബുകളായുള്ള ഓഫ്‌ലൈൻ മോഡ് (പാട്ടുകൾ, കലാകാരന്മാർ, ആൽബങ്ങൾ, പ്ലേലിസ്റ്റുകൾ).
- ക്രമീകരണങ്ങൾ › ഫീച്ചറുകൾ എന്നതിൽ ഓൺ/ഓഫ് ചെയ്യാവുന്ന 40-ലധികം ഫീച്ചറുകൾ.

## കോൺഫിഗറേഷൻ

ആദ്യ തവണ തുറക്കുമ്പോൾ, നിങ്ങളുടെ Navidrome സെർവർ വിലാസം (ഉദാഹരണത്തിന് `http://mon-serveur:4533`), ഉപയോക്തൃനാമം,
പാസ്‌വേഡ് എന്നിവ നൽകുക. തീമിന്റെ നിറം ക്രമീകരണങ്ങൾ › രൂപഭാവം എന്നതിൽ മാറ്റാം.

### deemix (ഐച്ഛികം)
Deezer-ൽ നിന്ന് Navidrome-ന്റെ സംഗീത ഫോൾഡറിലേക്ക് പാട്ടുകൾ ഡൗൺലോഡ് ചെയ്യാൻ നിങ്ങളുടെ സെർവറിൽ ഇൻസ്റ്റാൾ ചെയ്ത ഒരു ചെറിയ സേവനം (`server/` ഫോൾഡർ, `server/README-serveur.md` കാണുക)
Opus-ന് നിയന്ത്രിക്കാനാകും. Deezer ARL ആപ്പിൽ നൽകുന്നു.
ശ്രദ്ധിക്കുക: ഈ ഉപയോഗം Deezer-ന്റെ ഉപയോഗ നിബന്ധനകൾക്ക് വിരുദ്ധമാണ്.

## സ്വയം ബിൽഡ് ചെയ്യാൻ (Windows)

ആവശ്യമുള്ളവ: Node.js 20+, Android SDK ഉള്ള Android Studio, **JDK 21** (Java 27-ഓ അതിനുശേഷമുള്ളതോ ഉപയോഗിച്ച്
കംപൈൽ ചെയ്ത ക്ലാസുകൾ Gradle 8.14-ന് ഇതുവരെ വായിക്കാനാകില്ല).

```
npm install
npm run android:add     # android/ ഫോൾഡർ സൃഷ്ടിച്ച് തിരുത്തലുകൾ പ്രയോഗിക്കുന്നു
npm run sync            # വെബ് ബിൽഡ് + Capacitor സിങ്ക്
cd android
gradlew.bat assembleDebug
```

APK `android/app/build/outputs/apk/debug/app-debug.apk`-ൽ നിർമ്മിക്കപ്പെടുന്നു.

Gradle തെറ്റായ Java ഉപയോഗിക്കുന്നുണ്ടെങ്കിൽ, ബിൽഡ് ചെയ്യുന്നതിന് മുമ്പ് `JAVA_HOME` JDK 21-ലേക്ക് സജ്ജമാക്കുക:

```
set JAVA_HOME=C:\Program Files\Java\jdk-21.0.12.1
set PATH=%JAVA_HOME%\bin;%PATH%
```

സെർവർ ഇല്ലാതെ പരീക്ഷിക്കാൻ: `npm run mock` (വ്യാജ Navidrome, ലോഗിൻ `test` / `test`), തുടർന്ന് `npm run dev`.

## അറിയപ്പെടുന്ന പരിമിതികൾ
