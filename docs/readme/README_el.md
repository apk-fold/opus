# Opus

Εφαρμογή Android φτιαγμένη στα μέτρα σου για να ακούς τη μουσική σου από έναν διακομιστή [Navidrome](https://www.navidrome.org/) (Subsonic API).
Σκοτεινό θέμα με ρυθμιζόμενο χρώμα, κινούμενα εφέ GSAP, συγχρονισμένοι στίχοι, λειτουργία εκτός σύνδεσης και έλεγχος του deemix μέσα από την εφαρμογή.
Πακεταρισμένη ως APK με το [Capacitor](https://capacitorjs.com/), με διάταξη προσαρμοσμένη στο Galaxy Z Fold (κλειστό / ανοιχτό).

## Τι νέο στην v6
- **Εγγενές πρόγραμμα αναπαραγωγής Android (ExoPlayer/Media3), όπως στο Subtracks**: η ουρά αναπαράγεται από μια υπηρεσία Android, όχι πια από την ιστοσελίδα. Η μουσική συνεχίζει από κομμάτι σε κομμάτι με σβηστή οθόνη ή με την εφαρμογή στο παρασκήνιο, και η ειδοποίηση (αναπαραγωγή/παύση/προηγούμενο/επόμενο) ελέγχει το πραγματικό πρόγραμμα αναπαραγωγής.
- Περιορισμοί της εγγενούς λειτουργίας: χωρίς ισοσταθμιστή ή crossfade (αντικαθίστανται από την αδιάκοπη αναπαραγωγή του εγγενούς προγράμματος).

## Τι νέο στην v4
- Ένα κομμάτι δεν ξεκινά πια από τη μέση: η παλιά θέση συνέχισης εφαρμόζεται μόνο στο κομμάτι στο οποίο ανήκει.
- Πιο αξιόπιστη αναπαραγωγή στο παρασκήνιο (κλείδωμα CPU/Wi-Fi κατά την αναπαραγωγή, παρακολούθηση της μετάβασης στο επόμενο κομμάτι). Ρυθμίσεις › Αναπαραγωγή στο παρασκήνιο: κουμπί για την άρση του περιορισμού μπαταρίας.
- Εκτός σύνδεσης: ταξινόμηση καλλιτεχνών, άλμπουμ και λιστών (A→Z, πρόσφατα, περισσότερα κομμάτια, μεγαλύτερα) και μενού ⋯ › «Λήψη όλων των λιστών μου».
- Το APK μεταγλωττίζεται αυτόματα από το GitHub Actions σε κάθε ενημέρωση (καρτέλα Releases).

## Λήψη του APK

➡️ **[Λήψη του Opus v6 (`opus.apk`)](https://github.com/apk-fold/opus/raw/main/opus.apk)**, 4,6 MB. Το αρχείο φαίνεται επίσης
στη λίστα αρχείων του αποθετηρίου.

Άθροισμα SHA-256 για επαλήθευση του αρχείου: `63dc6c04ec14fc8d3ec5ed4c77b54b1d70bf6199b5b57f6256a27404fc1c16af`

Εγκατάσταση σε Android:
1. Κατέβασε το `opus.apk` απευθείας στο κινητό.
2. Άνοιξε το αρχείο. Το Android ζητά να επιτρέψεις την εγκατάσταση από αυτή την πηγή (browser ή διαχειριστής αρχείων): αποδέξου.
3. Πάτησε **Εγκατάσταση**.

Σημειώσεις:
- Είναι APK **debug** (υπογεγραμμένο με το κλειδί αποσφαλμάτωσης του Android Studio). Αν έχεις ήδη μια έκδοση του Opus με άλλη υπογραφή,
  απεγκατάστησέ την πρώτα.
- Σε Android 13+, επίτρεψε τις ειδοποιήσεις για το Opus (στοιχεία ελέγχου πολυμέσων στην οθόνη κλειδώματος) και βάλε την μπαταρία της εφαρμογής σε
  «Χωρίς περιορισμούς», ώστε η αναπαραγωγή να συνεχίζεται με σβηστή οθόνη.
- Το κινητό πρέπει να μπορεί να φτάσει στον διακομιστή Navidrome σου (για παράδειγμα μέσω Tailscale).

## Κύριες λειτουργίες

### Τι νέο στην v3
- **Χειρονομίες όπως στο iPhone** (Ρυθμίσεις › Χειρονομίες και συντομεύσεις): τράβηγμα προς τα κάτω στην κορυφή μιας σελίδας ανοίγει το μενού ⋯ της, σάρωση
  προς τα κάτω στο πρόγραμμα αναπαραγωγής ανοίγει το μενού του κομματιού, προς τα πάνω την ουρά, διπλό πάτημα στο εξώφυλλο = μου αρέσει,
  παρατεταμένο πάτημα σε κομμάτι, άλμπουμ, λίστα ή καλλιτέχνη = το μενού του, σάρωση κομματιού δεξιά = αναπαραγωγή μετά, αριστερά =
  προσθήκη στην ουρά. Όλα ρυθμίζονται.
- **Θέματα**: σκοτεινό, AMOLED (καθαρό μαύρο) και ανοιχτό.
- **Ανοιχτό Fold**: βιβλιοθήκη αριστερά, πρόγραμμα αναπαραγωγής σταθερό δεξιά με τους στίχους (ή την ουρά) από κάτω. Όταν κλείνει, η εφαρμογή
  επιστρέφει στην κανονική μορφή.
- **Φάκελοι λιστών**: τοπική οργάνωση στο κινητό (το Navidrome δεν υποστηρίζει φακέλους).
- **Εισαγωγή λιστών από Spotify, YouTube και YouTube Music** με σύνδεσμο, χωρίς κλειδί API: τα κομμάτια εντοπίζονται στη
  βιβλιοθήκη, όσα λείπουν μπορούν να σταλούν στο deemix, και η λίστα μπορεί να δημιουργηθεί ξανά στο Navidrome.
- **Ανίχνευση διπλότυπων**: το ίδιο κομμάτι σε πολλά αντίγραφα ή ποιότητες, η καλύτερη ποιότητα πρώτη.
- **deemix κατά περίπτωση**: ποιότητα (FLAC, 320, 128) και λίστα προορισμού επιλέγονται σε κάθε λήψη.
- **Android**: συντομεύσεις στο εικονίδιο της εφαρμογής (Flow, Εκτός σύνδεσης, Αναζήτηση) και widget αρχικής οθόνης.

### Ακρόαση και ανακάλυψη
- **Flow** (ατελείωτο mix με βάση το γούστο σου, με διαθέσεις), **Mix της ημέρας**, **ραδιόφωνα** από ένα κομμάτι ή έναν καλλιτέχνη.
- **Ξεχασμένα διαμάντια**, **Σαν σήμερα**, **Νέα από τους καλλιτέχνες σου**, **Τυφλό τεστ**, **Ιστορικό**, **Replay**.
- Συγχρονισμένοι στίχοι με άγγιγμα, ουρά, χρονοδιακόπτης ύπνου, ισοσταθμιστής, ReplayGain, crossfade, λειτουργία αυτοκινήτου.
- Λειτουργία εκτός σύνδεσης ανά καρτέλα (Κομμάτια, Καλλιτέχνες, Άλμπουμ, Λίστες).
- Πάνω από 40 λειτουργίες που ενεργοποιούνται ή απενεργοποιούνται στις Ρυθμίσεις › Λειτουργίες.

## Ρύθμιση

Στην πρώτη εκκίνηση, συμπλήρωσε τη διεύθυνση του διακομιστή Navidrome σου (για παράδειγμα `http://mon-serveur:4533`), το όνομα χρήστη και
τον κωδικό σου. Το χρώμα του θέματος αλλάζει στις Ρυθμίσεις › Εμφάνιση.

### deemix (προαιρετικό)
Το Opus μπορεί να ελέγχει μια μικρή υπηρεσία εγκατεστημένη στον διακομιστή σου (φάκελος `server/`, δες `server/README-serveur.md`) για να
κατεβάζει κομμάτια από το Deezer στον φάκελο μουσικής του Navidrome. Το ARL του Deezer εισάγεται στην εφαρμογή.
Προσοχή: αυτή η χρήση αντιβαίνει στους όρους χρήσης του Deezer.

## Μεταγλώττιση από εσένα (Windows)

Προαπαιτούμενα: Node.js 20+, Android Studio με το Android SDK, και **JDK 21** (το Gradle 8.14 δεν διαβάζει ακόμη κλάσεις
μεταγλωττισμένες με Java 27 ή νεότερη).

```
npm install
npm run android:add     # δημιουργεί τον φάκελο android/ και εφαρμόζει τις διορθώσεις
npm run sync            # build web + συγχρονισμός Capacitor
cd android
gradlew.bat assembleDebug
```

Το APK παράγεται στο `android/app/build/outputs/apk/debug/app-debug.apk`.

Αν το Gradle χρησιμοποιεί λάθος Java, όρισε το `JAVA_HOME` στο JDK 21 πριν από τη μεταγλώττιση:

```
set JAVA_HOME=C:\Program Files\Java\jdk-21.0.12.1
set PATH=%JAVA_HOME%\bin;%PATH%
```

Για δοκιμή χωρίς διακομιστή: `npm run mock` (ψεύτικο Navidrome, στοιχεία σύνδεσης `test` / `test`) και μετά `npm run dev`.

## Γνωστοί περιορισμοί
- Η εισαγωγή από Spotify / YouTube διαβάζει τις δημόσιες σελίδες αυτών των ιστότοπων, των οποίων η μορφή αλλάζει συχνά. Αν αποτύχει, η επικόλληση
  μιας λίστας «Καλλιτέχνης - Τίτλος» λειτουργεί πάντα. Χωρίς λογαριασμό διαβάζονται μόνο τα πρώτα 100 κομμάτια.
- Η λειτουργία Fold, το widget και οι χειρονομίες ελέγχθηκαν σε προσομοίωση, όχι ακόμη σε όλες τις συσκευές.
- Ο οπτικοποιητής είναι διακοσμητικός.
- Ο ισοσταθμιστής απαιτεί ο διακομιστής σου να επιτρέπει CORS στις ροές ήχου (`Access-Control-Allow-Origin`).
