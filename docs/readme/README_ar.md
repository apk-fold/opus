# Opus

تطبيق Android مصمّم خصيصًا للاستماع إلى موسيقاك من خادم [Navidrome](https://www.navidrome.org/) (واجهة Subsonic API).
سمة داكنة بلون قابل للضبط، وحركات GSAP، وكلمات أغانٍ متزامنة، ووضع دون اتصال، والتحكم في deemix من داخل التطبيق.
مُغلَّف كملف APK باستخدام [Capacitor](https://capacitorjs.com/)، بتخطيط ملائم لهاتف Galaxy Z Fold (مطويًا / مفتوحًا).

## الجديد في v6
- **مشغّل Android أصلي (ExoPlayer/Media3)، كما في Subtracks**: تُشغَّل قائمة الانتظار بخدمة Android، لا بصفحة الويب. تنتقل الموسيقى من مقطع إلى آخر والشاشة مطفأة أو التطبيق في الخلفية، والإشعار (تشغيل/إيقاف مؤقت/السابق/التالي) يتحكم في المشغّل الحقيقي.
- قيود الوضع الأصلي: لا معادل صوت ولا تلاشٍ متداخل (استُبدلا بالتشغيل المتواصل دون فواصل في المشغّل الأصلي).

## الجديد في v4
- لم يعد المقطع يبدأ من منتصفه: موضع الاستئناف القديم لا يُطبَّق إلا على المقطع الذي يخصه.
- تشغيل أقوى في الخلفية (قفل CPU/Wi-Fi أثناء التشغيل، ومراقبة الانتقال إلى المقطع التالي). الإعدادات › التشغيل في الخلفية: زر لإزالة قيود البطارية.
- دون اتصال: فرز الفنانين والألبومات وقوائم التشغيل (A→Z، الأحدث، الأكثر مقاطع، الأكبر حجمًا) وقائمة ⋯ › «تنزيل كل قوائم التشغيل الخاصة بي».
- يُبنى ملف APK تلقائيًا عبر GitHub Actions مع كل تحديث (تبويب Releases).

## تنزيل ملف APK

➡️ **[تنزيل Opus v6 (`opus.apk`)](https://github.com/apk-fold/opus/raw/main/opus.apk)**، بحجم 4.6 ميغابايت. يظهر الملف أيضًا
في قائمة ملفات المستودع.

بصمة SHA-256 للتحقق من الملف: `63dc6c04ec14fc8d3ec5ed4c77b54b1d70bf6199b5b57f6256a27404fc1c16af`

التثبيت على Android:
1. نزّل `opus.apk` مباشرة على الهاتف.
2. افتح الملف. سيطلب Android السماح بالتثبيت من هذا المصدر (المتصفح أو مدير الملفات): وافق.
3. اضغط **تثبيت**.

ملاحظات:
- هذا ملف APK بنسخة **debug** (موقّع بمفتاح تصحيح الأخطاء في Android Studio). إذا كانت لديك نسخة من Opus موقّعة بطريقة أخرى،
  فألغِ تثبيتها أولًا.
- على Android 13 فأحدث، اسمح بإشعارات Opus (عناصر التحكم بالوسائط على شاشة القفل) واضبط بطارية التطبيق على
  «غير مقيّد» كي يستمر التشغيل والشاشة مطفأة.
- يجب أن يتمكن الهاتف من الوصول إلى خادم Navidrome الخاص بك (مثلًا عبر Tailscale).

## الميزات الرئيسية

### الجديد في v3
- **إيماءات على طريقة iPhone** (الإعدادات › الإيماءات والاختصارات): السحب للأسفل أعلى الصفحة يفتح قائمة ⋯ الخاصة بها، والسحب
  للأسفل على المشغّل يفتح قائمة المقطع، وللأعلى قائمة الانتظار، والنقر المزدوج على الغلاف = إعجاب،
  والضغط المطوّل على مقطع أو ألبوم أو قائمة تشغيل أو فنان = قائمته، وسحب مقطع لليمين = تشغيله تاليًا، ولليسار =
  إضافته إلى قائمة الانتظار. كل شيء قابل للضبط.
- **السمات**: داكنة، AMOLED (أسود خالص)، وفاتحة.
- **Fold مفتوحًا**: المكتبة على اليسار، والمشغّل مثبّت على اليمين وتحته الكلمات (أو قائمة الانتظار). عند الطي يعود التطبيق
  إلى شكله العادي.
- **مجلدات قوائم التشغيل**: تنظيم محلي على الهاتف (Navidrome لا يدعم المجلدات).
- **استيراد قوائم تشغيل Spotify وYouTube وYouTube Music** عبر رابط، دون مفتاح API: يُبحث عن المقاطع في
  المكتبة، ويمكن إرسال المفقود منها إلى deemix، ويمكن إعادة إنشاء قائمة التشغيل في Navidrome.
- **كشف التكرار**: المقطع نفسه بعدة نسخ أو جودات، والأفضل جودةً أولًا.
- **deemix حسب كل حالة**: اختيار الجودة (FLAC، 320، 128) وقائمة التشغيل الهدف عند كل تنزيل.
- **Android**: اختصارات على أيقونة التطبيق (Flow، دون اتصال، البحث) وأداة للشاشة الرئيسية.

### الاستماع والاكتشاف
- **Flow** (مزيج لا ينتهي حسب ذوقك، مع حالات مزاجية)، **مزيج اليوم**، **محطات راديو** انطلاقًا من مقطع أو فنان.
- **جواهر منسية**، **في مثل هذا اليوم**، **جديد فنانيك**، **اختبار أعمى**، **السجل**، **Replay**.
- كلمات متزامنة يمكن لمسها، قائمة انتظار، مؤقت النوم، معادل صوت، ReplayGain، تلاشٍ متداخل، وضع السيارة.
- وضع دون اتصال مقسّم إلى ألسنة (المقاطع، الفنانون، الألبومات، قوائم التشغيل).
- أكثر من 40 ميزة يمكن تفعيلها أو تعطيلها من الإعدادات › الميزات.

## الإعداد

عند التشغيل الأول، أدخل عنوان خادم Navidrome الخاص بك (مثلًا `http://mon-serveur:4533`) واسم المستخدم و
كلمة المرور. يُغيَّر لون السمة من الإعدادات › المظهر.

### deemix (اختياري)
يمكن لـ Opus التحكم في خدمة صغيرة مثبّتة على خادمك (المجلد `server/`، راجع `server/README-serveur.md`) من أجل
تنزيل مقاطع من Deezer إلى مجلد موسيقى Navidrome. يُدخَل ARL الخاص بـ Deezer داخل التطبيق.
تنبيه: هذا الاستخدام مخالف لشروط استخدام Deezer.

## البناء بنفسك (Windows)

المتطلبات: Node.js 20+، وAndroid Studio مع Android SDK، و**JDK 21** (لا يستطيع Gradle 8.14 بعد قراءة الأصناف
المترجمة بـ Java 27 أو أحدث).

```
npm install
npm run android:add     # ينشئ المجلد android/ ويطبّق التصحيحات
npm run sync            # بناء الويب + مزامنة Capacitor
cd android
gradlew.bat assembleDebug
```

يُنتَج ملف APK في `android/app/build/outputs/apk/debug/app-debug.apk`.

إذا استخدم Gradle نسخة Java خاطئة، فاضبط `JAVA_HOME` على JDK 21 قبل البناء:

```
set JAVA_HOME=C:\Program Files\Java\jdk-21.0.12.1
set PATH=%JAVA_HOME%\bin;%PATH%
```

للتجربة دون خادم: `npm run mock` (خادم Navidrome وهمي، بيانات الدخول `test` / `test`) ثم `npm run dev`.

## القيود المعروفة
- يقرأ استيراد Spotify / YouTube الصفحات العامة لهذه المواقع، وتنسيقها يتغير كثيرًا. إذا فشل، فإن لصق
  قائمة «الفنان - العنوان» يعمل دائمًا. دون حساب، لا تُقرأ إلا أول 100 مقطع.
- جرى التحقق من وضع Fold والأداة والإيماءات عبر المحاكاة، ولم تُجرَّب بعد على كل الأجهزة.
- المؤثر البصري للصوت تزييني فقط.
- يتطلب معادل الصوت أن يسمح خادمك بـ CORS على تدفقات الصوت (`Access-Control-Allow-Origin`).
