# Opus

แอป Android ที่ทำขึ้นเองสำหรับฟังเพลงจากเซิร์ฟเวอร์ [Navidrome](https://www.navidrome.org/) (Subsonic API)
ธีมมืดที่ปรับสีได้ แอนิเมชัน GSAP เนื้อเพลงซิงค์ โหมดออฟไลน์ และควบคุม deemix ได้จากในแอป
แพ็กเป็น APK ด้วย [Capacitor](https://capacitorjs.com/) พร้อมเลย์เอาต์ที่ปรับให้เข้ากับ Galaxy Z Fold (พับ / กาง)

## มีอะไรใหม่ใน v6
- **เครื่องเล่น Android แบบเนทีฟ (ExoPlayer/Media3) แบบเดียวกับ Subtracks**: คิวเพลงเล่นโดยเซอร์วิสของ Android ไม่ใช่หน้าเว็บอีกต่อไป เพลงจะเล่นต่อกันได้แม้ปิดหน้าจอหรือแอปทำงานเบื้องหลัง และการแจ้งเตือน (เล่น/หยุด/ก่อนหน้า/ถัดไป) จะควบคุมเครื่องเล่นจริง
- ข้อจำกัดของโหมดเนทีฟ: ไม่มีอีควอไลเซอร์และการเฟดข้ามเพลง (แทนที่ด้วยการเล่นต่อเนื่องไร้ช่องว่างของเครื่องเล่นเนทีฟ)

## มีอะไรใหม่ใน v4
- เพลงจะไม่เริ่มเล่นจากกลางเพลงอีกแล้ว: ตำแหน่งเล่นต่อเดิมจะใช้กับเพลงที่เป็นเจ้าของตำแหน่งนั้นเท่านั้น
- การเล่นเบื้องหลังเสถียรขึ้น (ล็อก CPU/Wi-Fi ระหว่างเล่น เฝ้าดูการข้ามไปเพลงถัดไป) การตั้งค่า › การเล่นเบื้องหลัง: ปุ่มสำหรับยกเลิกข้อจำกัดแบตเตอรี่
- ออฟไลน์: เรียงศิลปิน อัลบั้ม และเพลย์ลิสต์ (A→Z, ล่าสุด, เพลงมากที่สุด, ขนาดใหญ่ที่สุด) และเมนู ⋯ › "ดาวน์โหลดเพลย์ลิสต์ทั้งหมดของฉัน"
- APK ถูกคอมไพล์อัตโนมัติด้วย GitHub Actions ทุกครั้งที่อัปเดต (แท็บ Releases)

## ดาวน์โหลด APK

➡️ **[ดาวน์โหลด Opus v6 (`opus.apk`)](https://github.com/apk-fold/opus/raw/main/opus.apk)** ขนาด 4.6 MB ไฟล์นี้ยังเห็นได้
ในรายการไฟล์ของรีโพซิทอรี

ค่าแฮช SHA-256 สำหรับตรวจสอบไฟล์: `63dc6c04ec14fc8d3ec5ed4c77b54b1d70bf6199b5b57f6256a27404fc1c16af`

การติดตั้งบน Android:
1. ดาวน์โหลด `opus.apk` ลงโทรศัพท์โดยตรง
2. เปิดไฟล์ Android จะขอให้อนุญาตการติดตั้งจากแหล่งนี้ (เบราว์เซอร์หรือตัวจัดการไฟล์): กดยอมรับ
3. แตะ **ติดตั้ง**

หมายเหตุ:
- นี่คือ APK แบบ **debug** (ลงนามด้วยคีย์ debug ของ Android Studio) หากคุณมี Opus เวอร์ชันที่ลงนามด้วยวิธีอื่นอยู่แล้ว
  ให้ถอนการติดตั้งก่อน
- บน Android 13 ขึ้นไป ให้อนุญาตการแจ้งเตือนสำหรับ Opus (ตัวควบคุมสื่อบนหน้าจอล็อก) และตั้งค่าแบตเตอรี่ของแอปเป็น
  "ไม่จำกัด" เพื่อให้เล่นต่อได้เมื่อปิดหน้าจอ
- โทรศัพท์ต้องเข้าถึงเซิร์ฟเวอร์ Navidrome ของคุณได้ (เช่น ผ่าน Tailscale)

## ฟีเจอร์หลัก

### มีอะไรใหม่ใน v3
- **ท่าทางแบบ iPhone** (การตั้งค่า › ท่าทางและทางลัด): ดึงลงที่ด้านบนของหน้าเพื่อเปิดเมนู ⋯ ของหน้านั้น ปัด
  ลงบนเครื่องเล่นเพื่อเปิดเมนูเพลง ปัดขึ้นเพื่อเปิดคิว แตะสองครั้งที่ปก = ถูกใจ
  กดค้างที่เพลง อัลบั้ม เพลย์ลิสต์ หรือศิลปิน = เมนูของรายการนั้น ปัดเพลงไปทางขวา = เล่นถัดไป ไปทางซ้าย =
  เพิ่มลงคิว ทุกอย่างตั้งค่าได้
- **ธีม**: มืด, AMOLED (ดำสนิท) และสว่าง
- **Fold ที่กางออก**: คลังเพลงทางซ้าย เครื่องเล่นยึดไว้ทางขวาพร้อมเนื้อเพลง (หรือคิว) ด้านล่าง เมื่อพับ แอป
  จะกลับเป็นแบบปกติ
- **โฟลเดอร์เพลย์ลิสต์**: จัดระเบียบไว้ในโทรศัพท์ (Navidrome ไม่รองรับโฟลเดอร์)
- **นำเข้าเพลย์ลิสต์จาก Spotify, YouTube และ YouTube Music** ด้วยลิงก์ ไม่ต้องใช้คีย์ API: ค้นหาเพลงที่ตรงกันใน
  คลังเพลง เพลงที่ขาดส่งไป deemix ได้ และสร้างเพลย์ลิสต์ใหม่ใน Navidrome ได้
- **ตรวจจับเพลงซ้ำ**: เพลงเดียวกันหลายสำเนาหรือหลายคุณภาพ คุณภาพดีที่สุดขึ้นก่อน
- **ตั้งค่า deemix ทีละครั้ง**: เลือกคุณภาพ (FLAC, 320, 128) และเพลย์ลิสต์ปลายทางทุกครั้งที่เริ่มดาวน์โหลด
- **Android**: ทางลัดที่ไอคอนแอป (Flow, ออฟไลน์, ค้นหา) และวิดเจ็ตหน้าจอหลัก

### การฟังและการค้นพบ
- **Flow** (มิกซ์ไม่รู้จบตามรสนิยมของคุณ พร้อมอารมณ์), **มิกซ์ประจำวัน**, **วิทยุ** จากเพลงหรือศิลปิน
- **เพลงดีที่ถูกลืม**, **วันนี้ในอดีต**, **ผลงานใหม่จากศิลปินของคุณ**, **ทายเพลง**, **ประวัติ**, **Replay**
- เนื้อเพลงซิงค์ที่แตะได้, คิว, ตั้งเวลาปิด, อีควอไลเซอร์, ReplayGain, เฟดข้ามเพลง, โหมดรถยนต์
- โหมดออฟไลน์แยกตามแท็บ (เพลง, ศิลปิน, อัลบั้ม, เพลย์ลิสต์)
- ฟีเจอร์มากกว่า 40 อย่างที่เปิดหรือปิดได้ใน การตั้งค่า › ฟีเจอร์

## การตั้งค่าเริ่มต้น

เมื่อเปิดครั้งแรก ให้กรอกที่อยู่เซิร์ฟเวอร์ Navidrome ของคุณ (เช่น `http://mon-serveur:4533`) ชื่อผู้ใช้ และ
รหัสผ่าน เปลี่ยนสีธีมได้ใน การตั้งค่า › ลักษณะที่ปรากฏ

### deemix (ไม่บังคับ)
Opus ควบคุมเซอร์วิสเล็ก ๆ ที่ติดตั้งบนเซิร์ฟเวอร์ของคุณได้ (โฟลเดอร์ `server/` ดู `server/README-serveur.md`) เพื่อ
ดาวน์โหลดเพลงจาก Deezer ลงในโฟลเดอร์เพลงของ Navidrome โดยกรอก ARL ของ Deezer ในแอป
คำเตือน: การใช้งานลักษณะนี้ขัดต่อข้อกำหนดการใช้งานของ Deezer

## คอมไพล์เอง (Windows)

สิ่งที่ต้องมี: Node.js 20+, Android Studio พร้อม Android SDK และ **JDK 21** (Gradle 8.14 ยังอ่านคลาสที่
คอมไพล์ด้วย Java 27 ขึ้นไปไม่ได้)

```
npm install
npm run android:add     # สร้างโฟลเดอร์ android/ และใส่แพตช์
npm run sync            # build เว็บ + ซิงค์ Capacitor
cd android
gradlew.bat assembleDebug
```

APK จะถูกสร้างที่ `android/app/build/outputs/apk/debug/app-debug.apk`

หาก Gradle ใช้ Java ผิดเวอร์ชัน ให้ตั้ง `JAVA_HOME` ไปที่ JDK 21 ก่อนคอมไพล์:

```
set JAVA_HOME=C:\Program Files\Java\jdk-21.0.12.1
set PATH=%JAVA_HOME%\bin;%PATH%
```

ลองใช้โดยไม่ต้องมีเซิร์ฟเวอร์: `npm run mock` (Navidrome จำลอง บัญชี `test` / `test`) แล้วตามด้วย `npm run dev`

## ข้อจำกัดที่ทราบ
- การนำเข้าจาก Spotify / YouTube อ่านหน้าสาธารณะของเว็บเหล่านั้น ซึ่งรูปแบบเปลี่ยนบ่อย หากล้มเหลว การวาง
  รายการ "ศิลปิน - ชื่อเพลง" ยังใช้ได้เสมอ หากไม่มีบัญชีจะอ่านได้เพียง 100 เพลงแรก
- โหมด Fold วิดเจ็ต และท่าทาง ตรวจสอบด้วยการจำลองแล้ว แต่ยังไม่ได้ทดสอบบนทุกอุปกรณ์
- ภาพเคลื่อนไหวตามเสียงมีไว้เพื่อความสวยงามเท่านั้น
- อีควอไลเซอร์ต้องการให้เซิร์ฟเวอร์ของคุณอนุญาต CORS บนสตรีมเสียง (`Access-Control-Allow-Origin`)
